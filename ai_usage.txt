Practice 5 AI Usage

I used ChatGPT while working on Practice 5.

Task 1:
- ChatGPT helped me understand the required changes for if/else, multiline blocks, and the ! operator.
- It suggested changes to the lexer so that ! and != are distinguished using one-byte lookahead and braces are handled as regular tokens.
- It helped implement the parser changes for if statements and blocks, including nested blocks, optional else branches, and exit inside a block.
- It helped add the If, Block, and Not AST nodes and their AST printer methods.
- I tested the generated AST against the examples from the practice specification.

Task 2:
- ChatGPT explained the difference between semantic scopes and LLVM basic blocks.
- It helped change the symbol table into a stack of scopes.
- It suggested the implementation for entering and leaving block scopes and looking up variables from the innermost scope outward.
- It helped implement shadowing, same-scope redeclaration checks, bool checking for if conditions, and bool checking for the ! operator.
- It helped verify that Var and Assign nodes refer to the correct declaration through node.decl.
- I tested scope lookup, shadowing, use after scope, redeclaration, and type errors.

Task 3:
- ChatGPT explained how if/else is represented with then, else, and merge LLVM basic blocks and conditional branches.
- It helped implement LLVM code generation for If, Block, and Not nodes.
- It helped ensure that a branch is not emitted after a block that already terminates with return.
- The first implementation for entry-block allocas produced invalid LLVM because some instructions were inserted after a terminator. ChatGPT helped diagnose this from the generated IR.
- We changed the implementation to first traverse the AST and allocate all declaration slots in the entry block before generating executable instructions.
- ChatGPT helped test nested if statements, shadowing, exit inside a branch, if without else, integer widening inside a branch, and assignments in both branches.
- It also helped verify the generated IR with LLVM mem2reg. The optimized IR contained a phi instruction for a variable assigned in both branches.

Testing:
- ChatGPT helped design additional positive and negative tests for Practice 5.
- The tests cover if/else, nested if, shadowing with different types, ! together with !=, if without else, assignments in both branches, integer widening, exit inside a nested branch, non-bool conditions, ! on an integer, use after scope, same-scope redeclaration, incorrect assignment to a shadowed variable, incorrect brace placement, empty blocks, and statements after exit.
- ChatGPT also helped create AST snapshot tests for the new If, Block, and Not nodes.
- I ran the complete test suite and checked the results myself.

I reviewed the suggested code, ran the compiler and LLVM tools locally, inspected the generated AST and LLVM IR, and verified the behavior with the test suite.
